# Translation review

Thank you for checking the Study Planner app in your language. These are the screens added since the app was first translated: grades, attendance, activities (clubs, sports, work), rotating timetables (Day A / Day B), subtasks, the week view and homework.

## Files

| File | Language |
| --- | --- |
| `hi.csv` | Hindi |
| `or.csv` | Odia |
| `es.csv` | Spanish |

Open your file in Excel or Google Sheets. Each row is one piece of text in the app.

## What to do

For each row, read the **English** text and the translation in your language, then:

1. Write **Y** in **OK?** if the translation is correct and sounds natural.
2. Otherwise write **N** and put your better wording in **Suggested change**.

Please check that:

- the meaning matches the English;
- it sounds like something a student would actually read in an app (not too formal, not word-for-word);
- the same thing is called the same name everywhere (for example "class", "exam", "subtask").

## Things to keep as they are

- Words in curly brackets, like `{title}` or `{count}`, are filled in by the app. Keep them exactly as written, but move them to wherever they belong in your sentence. The **Notes** column says what each one becomes.
- Rows ending in `.one` and `.other` are the singular (1) and plural forms of the same text.
- Rows whose key contains `A11y` are read aloud by screen readers for blind and low-vision users. They are not shown on screen, but they still matter.

Rows marked **QUESTION** in the Notes column are the ones the developer is least sure about. Please look at those first.

## Sending it back

Save the file (keep it as CSV) and send it back. Only the **OK?** and **Suggested change** columns need to change.
